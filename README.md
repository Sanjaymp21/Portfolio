# SANJAY M — Developer Portfolio

A modern, responsive, and aesthetic developer portfolio website built for **SANJAY M** (B.Tech Information Technology Student at Bannari Amman Institute of Technology & Aspiring Software Developer).

## 🚀 Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism System
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (Outfit & Inter)
- **Deployment**: Ready for [Vercel](https://vercel.com/) / [GitHub Pages](https://pages.github.com/)

---

## ✨ Features

- **Hero Section**: Live developer status indicator, dynamic code inspection terminal visual, and fast action CTAs.
- **About Me**: Academic background, career goal card, and 4 core focus pillars (*Student, Software Developer Aspirant, AI & Tech Enthusiast, UI/UX Designer*).
- **Skills Showcase**: Clean categorized competencies (*Programming, Web Development, Design*) with custom tags and zero fake percentage progress bars.
- **Projects Portfolio**: Interactive project cards with category filtering, modal detail views, tech badges, and medical/educational disclaimer for *EndoJourney AI*.
- **Education & Milestones**: Detailed B.Tech timeline, 10th (96%) and 12th (90%) academic distinctions, School SPL leadership, and verified certifications (AWS, Python, NPTEL).
- **Resume Integration**: Direct PDF download CTA linked to `/assets/Sanjay-M-Resume.pdf`.
- **Contact**: Direct email mailto link + 1-click clipboard copy with toast feedback, and verified GitHub & LinkedIn profile links.
- **Dark / Light Mode**: Seamless system-aware theme toggle with persistent preferences.
- **Accessibility & Responsiveness**: Mobile navigation drawer, scroll-to-top button, semantic HTML, and active section tracking.

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 📄 Updating Your Resume PDF

Place your official resume PDF file at:
```
public/assets/Sanjay-M-Resume.pdf
```
The portfolio's "Download Resume" buttons and links are pre-wired to this path.

---

## 🌐 Deploy to Vercel

1. Push your repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository.
4. Select **Vite** as the framework preset (automatic detection).
5. Click **Deploy**!
